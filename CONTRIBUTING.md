# Contributing

Everyone is welcome to improve this template. Begin with a small, reviewable change: update documentation, clarify a notebook cell, add a test, or suggest an issue.

1. Fork the repository and create a descriptive branch.
2. Make the change and run `python -m pytest`.
3. If outputs change, regenerate them and explain why.
4. Open a pull request that states the purpose, data implications, and checks run.

Do not commit credentials, sensitive data, or files from `data/raw/`. For changes involving community, Tribal, sensitive, or restricted data, pause and follow the applicable governance process before sharing any files or metadata.

Use kind, plain language in reviews. Ask questions before assuming intent, and request changes in terms of the project goal rather than a contributor's skill level.
