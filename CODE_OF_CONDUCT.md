# Code of Conduct

We are committed to a respectful, inclusive learning environment. Participate with curiosity, credit others' contributions, and welcome questions at every skill level.

Harassment, discriminatory language, personal attacks, or sharing data beyond agreed permissions are not acceptable. If a concern arises, contact the repository maintainer, Lilly Jones (lijo8146@colorado.edu), privately. Concerns will be handled respectfully and with attention to safety.
